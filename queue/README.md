# 게시물 대기열

이 폴더의 `.json` 파일 하나가 게시물 하나입니다. 프로그램은 매일 **파일 이름 순서대로** 아직 올리지 않은 것을 하나 꺼내 이미지로 만들어 올립니다.

- 이미 올린 파일은 `data/history.json`에 기록되므로 지우지 않아도 다시 올라가지 않습니다.
- 올리기 전에 내용을 고치고 싶으면 해당 파일을 직접 수정하면 됩니다.
- 순서를 바꾸고 싶으면 파일 이름의 번호를 바꾸면 됩니다.
- 이미 올린 게시물을 다시 올리려면 파일 이름을 바꿉니다(예: `001.json` → `001-repost.json`). 기록에 없는 새 이름이라 다시 올라가고, 주제가 같으면 표지의 시리즈 번호도 원래 번호를 그대로 씁니다. 인스타그램에 있던 기존 게시물은 직접 보관하거나 삭제해야 합니다.
- 남은 게시물이 5개 이하가 되면 GitHub Actions 실행 결과에 경고가 표시되고, 0개가 되면 실행이 실패해 이메일 알림이 옵니다.

## 게시물 추가하기

1. 마지막 번호 다음부터 `031.json`, `032.json`처럼 파일을 만듭니다.
2. PC에서 `npm install` 후 `npm run check`를 실행하면 남은 게시물 전체를 검사합니다. 글이 길어 카드에 들어가지 않는 게시물도 여기서 걸러집니다.
3. GitHub 저장소의 `queue` 폴더에 새 파일을 올립니다.

Claude에게 맡길 때는 이 폴더에서 "다음 달 치 게시물 30개 만들어 줘"라고 요청하면 됩니다. 아래 작성 기준과 `data/history.json`, 기존 파일의 `topic`을 보고 겹치지 않게 씁니다.

## 작성 기준

계정 정보(분야, 독자, 말투, 시리즈 목록)는 `config.json`에 있습니다.

### 좋은 게시물

- 주제가 좁고 구체적입니다. 분야 전체를 훑지 않고, 독자가 자주 하는 실수 하나나 막히는 지점 하나를 다룹니다.
- 표지는 독자가 자기 상황을 떠올리며 멈추게 만듭니다.
- 카드는 표지 → 한눈에 보기 → 본문 4장 → 전·후 예시 → 마무리, 총 8장입니다.
- 본문 카드 4장은 각각 '공감되는 상황 → 왜 그런지 → 이렇게 해 보세요' 흐름입니다.
- 실천 항목은 오늘 당장 할 수 있는 행동입니다. 다짐이 아니라, 무엇을 어디에 어떻게 적을지까지 알 수 있어야 합니다.
- 게시물마다 **전·후 예시**를 넣습니다. 원칙만 말하는 글은 어디서나 볼 수 있으므로, 아쉬운 기록과 고쳐 쓴 기록을 나란히 보여 줍니다. 예시는 학생이 직접 쓰는 메모·보고서·질문 문장으로 만들고(세특 문장 자체는 교사가 쓰므로 예시로 쓰지 않음), 실제 사례인 것처럼 꾸미지 않습니다.
- 올라갈 시기의 독자 상황(학기 초, 시험 기간, 학기 말, 방학)에 맞는 주제를 고릅니다.

### 댓글 안내 문구

"댓글에 '입시' 남기면 세특 무료 자료 3종" 안내는 프로그램이 표지 하단, 마무리 카드, 캡션(첫 문단 뒤와 맨 끝)에 자동으로 넣습니다. 게시물 파일에는 쓰지 않습니다. 문구는 `config.json`의 `cta`에서 바꿉니다.

### 순서와 표지 색

- 같은 시리즈의 게시물 6개를 연달아 배치합니다. 인스타그램 피드는 한 줄에 3개씩 보이므로, 6개 묶음이 같은 색 두 줄로 보입니다.
- 표지와 강조 색은 시리즈에 따라 자동으로 정해집니다 (`config.json`의 `theme.series`). 30개를 만든다면 다섯 시리즈를 6개씩, 시리즈 단위로 번호를 이어 붙입니다.
- 계열별 전략 시리즈 안에서는 네 계열(교육·인문·자연·메디컬)을 고르게 다룹니다.

### 사실에 관한 규칙

검수 없이 올라가는 입시 정보이므로 아래를 지킵니다. (`config.json`의 `content.rules`와 같은 내용)

- 통계 수치, 연구 결과, 특정 인물의 사례를 지어내지 않습니다.
- 세특을 포함한 생기부는 교사가 작성한다는 사실을 전제로, 학생이 직접 할 수 있는 일에 초점을 둡니다.
- 해마다 바뀌는 제도 세부 사항(기재 항목과 글자 수, 대입 반영 여부, 대학별 평가 기준, 전형 일정)은 단정하지 않습니다. 언급해야 하면 학교나 대학 공지를 확인하라고 안내합니다.
- 특정 대학·학과의 합격 사례나 합격 가능성, 성적 향상·합격 보장 표현을 쓰지 않습니다.
- 대필, 허위·과장 기재처럼 규정에 어긋나는 방법을 권하지 않습니다.
- 계정 운영자의 경험담이나 '생기부 엔트로피'의 구성·가격·효과를 지어내지 않습니다.
- 의학·심리 상담이 필요한 주제는 다루지 않습니다.

### 파일 형식

`sample/sample-post.json`이 그대로 본보기입니다. 글자 수는 이모지와 `**`를 뺀 기준이며, 넘으면 글씨가 작아지거나 검사에서 실패합니다.

| 항목 | 내용 | 글자 수 |
| --- | --- | --- |
| `topic` | 주제 한 문장 (중복 방지 기록용, 카드에는 안 나옴) | 자유 |
| `series` | `config.json`의 시리즈 중 하나 | - |
| `cover.title_line1` / `title_line2` | 표지 제목 두 줄. 둘째 줄이 강조 색 | 9자 / 10자 |
| `cover.subtitle` | 표지 부제 | 22자 |
| `header.title` / `subtitle` | 본문 카드마다 위에 반복되는 제목과 설명 | 22자 / 24자 |
| `summary.items[]` | 본문 카드와 같은 순서의 `title`, `desc` | 14자 / 22자 |
| `summary.closing` | 요약 카드 마지막 한 줄 | 26자 |
| `details[].title` | 본문 카드 제목 (4개) | 14자 |
| `details[].paragraphs` | 공감 → 이유 순서의 문단 2개 | 각 60자 |
| `details[].action_heading` | 실천 목록 머리말 | 14자 |
| `details[].actions` | 실천 항목 3개 | 각 26자 |
| `details[].tip` | 한 줄 팁, 이모지로 시작 | 42자 |
| `example.heading` | 예시 카드 제목 (예: "문장, 이렇게 바꿔요") | 16자 |
| `example.pairs[]` | 전·후 예시 2쌍. `before`는 아쉬운 기록, `after`는 고쳐 쓴 기록 | 24자 / 60자 |
| `outro.headline` | 마무리 문구 두 줄 (`\n`으로 줄바꿈) | 줄당 12자 |
| `outro.lines` | 격려 문장 2개 | 각 32자 |
| `caption` | 인스타그램 캡션 본문. 해시태그는 넣지 않음 | 1,500자 |
| `hashtags` | 이 게시물만의 해시태그 3~5개 (공통 태그는 자동으로 붙음) | - |

- 카드 문구에서 강조할 구절은 `**이렇게**` 감쌉니다. 카드 하나에 1~3곳, 표지와 제목류에는 쓰지 않습니다.
- 이모지는 가볍게 씁니다. 표지 제목 줄마다 0~1개, 팁 앞에 1개 정도입니다.
